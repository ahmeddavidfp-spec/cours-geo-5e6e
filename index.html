Le parcours de geographie d'Ines Cabossart

Huit modules, un theme officiel par annee (5e puis 6e). Chaque module se debloque quand le precedent est reussi a 60% ou plus. Ta progression est enregistree automatiquement dans ce navigateur.

Comment ca marche

Chaque module suit le meme format : theorie (avec de vraies cartes), entrainement (flashcards, jeu de reperage sur carte, quiz sans note), puis examen note (60% pour debloquer la suite, essais illimites). Tout est detaille dans l'accueil de chaque module.
